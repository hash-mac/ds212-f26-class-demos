# COMP/STAT 212 Class Demo Files

## Introduction

This repository contains the code demos performed in the COMP/STAT 212 Intermediate Data Science class taught at Macalester College in Fall 2026.


## How to Navigate

Each session demos are located in a separate directory prefixed with session date in `MMDD` format, eg, the session on `January 25th` will have a directory starting with `0125`.
